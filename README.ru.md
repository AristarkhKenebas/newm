# newm

**Wayland-композитор для ноутбуков и тачпадов: ваши окна на бесконечной стене.**

[English](README.md) · **Русский**

[![newm](docs/assets/screenshot.png)](https://youtu.be/4I_IHbP-iNQ)

</div>

Обычные оконные менеджеры втискивают окна в экран. newm раскладывает их по бесконечной
стене из плиток, а экран — это окно на эту стену. Тремя пальцами вы двигаетесь по ней,
четырьмя приближаете и отдаляете. При отдалении окна получают новый размер, так что ими
удобно пользоваться при любом масштабе.

## Что вы получаете

- **Сделан для тачпада.** Движение, масштаб, обзор всех окон и лаунчер — всё жестами, с
  следованием за пальцами; анимации по умолчанию выключены, плавные анимации newm — одной
  строкой (`animations { preset = "newm" }` или каждая по имени, как в Hyprland). Logo + тянуть
  мышью двигает окна и меняет их размер.
- **Обзор.** Нажмите Logo: все окна сразу. Наведите на одно, щёлкните — и вы там.
- **Красиво сразу.** Скруглённые окна с гладкими краями, размытие за полупрозрачными
  окнами, цвета из ваших обоев, светлая или тёмная тема для newm и ваших программ вместе.
- **Своя панель.** Острова у верхнего края: окно, часы с календарём, трей с меню программ,
  Wi-Fi, Bluetooth, звук, батарея, питание и быстрые настройки как на телефоне (яркость,
  кофеин, светлая или тёмная тема, ...).
- **Встроено, без лишних программ:** экран блокировки, лаунчер, снимки экрана (область, окно,
  экран или несколько окон целиком из обзора), история буфера обмена (Logo+V) и подсказка по
  клавишам (Logo+/).
- **Программы, которые не бывают маленькими** (Spotify), рисуются в форме своей плитки, а не
  обрезаются.
- **Меняйте на ходу.** Сохраните конфигурацию, и newm сразу её применит. Ошибка
  появится карточкой с номером строки, а newm оставит рабочие настройки. Сломанная
  конфигурация никогда не даст чёрный экран.
- **Конфигурация на вашем языке.** Kotlin (`config.kts`, родной для newm), Lua, JSON или Nix.
  Старый `config.py` от newm тоже работает.
- **Дружит с тем, что у вас уже есть.** waybar или любая другая панель (или никакой),
  mako, swaybg, программы X11, демонстрация экрана через порталы.

## Быстрый старт

### NixOS

В вашем flake:

```nix
inputs.newm.url = "github:AristarkhKenebas/newm";
```

и в конфигурации системы:

```nix
imports = [ newm.nixosModules.default ];
programs.newm.enable = true;
```

`sudo nixos-rebuild switch`, затем выберите «newm» на экране входа или наберите `newm` в
текстовой консоли. Попробовать без установки: `nix run github:AristarkhKenebas/newm` из
текстовой консоли. Подробнее — в [Установке](docs/ru/install.md#nixos).

### Arch и другие

Нужны Java 27, драйвер видеокарты (Mesa или NVIDIA 545+) и терминал.

```sh
git clone https://github.com/AristarkhKenebas/newm
cd newm
./install.sh
```

Затем наберите `newm` в текстовой консоли или выберите «newm» на экране входа. Нужные
библиотеки и помощники перечислены в [Установке](docs/ru/install.md#arch-и-другие-дистрибутивы).

### Первые клавиши

При первом запуске newm запишет вашу конфигурацию в `~/.config/newm/config.kts`, с пояснением
к каждой настройке.

- **Logo+/** — все клавиши с описанием;
- **Logo+Return** — терминал;
- **Logo+D** — лаунчер;
- **Logo** отдельно — все окна сразу;
- **Logo+H/J/K/L** — перемещение; **Logo+S** — два окна рядом;
- **Logo+Shift+Escape** — выход из сеанса.

## Об этом newm

newm написал Jonas Bucher на Python поверх pywm ([jbuchermn/newm](https://github.com/jbuchermn/newm)),
и там он больше не поддерживается. Здесь newm продолжается:

- перенесён на Kotlin, один в один по поведению;
- работает на библиотеке композиторов [Caulis](https://github.com/AristarkhKenebas/caulis)
  вместо pywm и wlroots;
- с исправлениями старых проблем newm и новыми частями: панель и быстрые настройки, экран
  блокировки, лаунчер, снимки экрана, история буфера обмена, перезагрузка конфигурации при
  сохранении, другие языки конфигурации, документация.

Исходный код на Python лежит в [`legacy/`](legacy) для справки.
