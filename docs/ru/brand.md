# Облик Jadefire

Собственный облик newm: светящийся глаз ящера в темноте — глубокий изумруд перетекает в нефрит,
золотистый янтарь вокруг зрачка-щели, кольцо огня по краю, и всё это на почти чёрном зелёном.
Включается одной строкой:

```kotlin
theme = "jadefire"
```

Он задаёт всё, о чём ваша конфигурация молчит сама:

- **цвета** панели, её меню, карточек уведомлений, сообщений композитора и экрана блокировки —
  тёмные и светлые (`colors { source = "jadefire" }` задаёт только их; он есть и в меню цветов);
- **рамку фокуса**: шейдер `"jadefire"` — нефрит перетекает в янтарь вдоль рамки, по кругу бежит
  искра, срочное окно пульсирует углями (`focus { shader = "jadefire" }`);
- **обои**: `"dragon-eye"`, дышащую радужку, чей зрачок-щель следит за указателем
  (`background { shader = "dragon-eye" }`). Своя картинка (`background { path }`) остаётся на месте.

То, что вы задали сами, всегда важнее: `theme = "jadefire"` и `focus { width = 2.0 }` — это
Jadefire с более тонкой рамкой.

С Jadefire newm пишет их в `~/.cache/newm/colors.json` и `colors.css` (и `-light`) —
`@define-color jade #3ddc97;` — для waybar, GTK и ваших скриптов; а также по ролям:
`background`, `surface`, `text`, `accent`, `highlight`, `alert`.

К нему подходят: терминал в этих цветах (foot: `background=0b110e`, `foreground=e8f0ea`,
`regular2=3ddc97`, `regular3=f2b33d`, `regular1=e8552d`) и тема курсора вроде Bibata Modern
Classic (`cursor { theme = "Bibata-Modern-Classic"; size = 24 }`).

## Обои

Живые обои newm нарисованы в этих цветах (каждые принимают и ваши `shaderColors`):

| Имя | Что |
|---|---|
| `dragon-eye` | дышащая радужка ящера; зрачок-щель следит за указателем и сужается, когда тот быстро движется; иногда моргает |
| `ember-sky` | нефритовые и янтарные занавесы света над ночным небом; искры поднимаются и собираются вокруг указателя |
| `scales` | переливающаяся драконья чешуя в темноте; от каждого щелчка расходится рябь |
| `deep-forest` | спокойная туманная тёмная зелень; светящиеся споры плывут по медленным течениям и сторонятся указателя |
| `molten` | медленные капли лавовой лампы из янтаря и углей с нефритовым свечением; указатель — тёплая капля |

Их настройки — в [списке всех настроек](settings.md#background--).
