# Каждый день

[English](../en/using.md) · **Русский**

## Стена

Большинство оконных менеджеров размещают окна на экране. newm размещает их на бесконечной
**стене** из плиток, а экран показывает её часть:

```
   ┌────────┬────────┬────────┐
   │ editor │ terminal        │      ← окно занимает одну плитку или несколько
   ├────────┼────────┼────────┤
   │ browser         │ music  │
   └────────┴────────┴────────┘
        экран показывает 2×2 плитки; отдалитесь, чтобы увидеть больше
```

- Сначала экран показывает 2 × 2 плитки; первое окно занимает одну, посередине. Новое окно
  открывается **справа от того, в котором вы** (окна правее сдвигаются на плитку), и вид
  переходит к нему. Диалог или просмотр фото программы открывается **под её окном**
  (см. [Где открываются окна](#где-открываются-окна)).
- Новое окно получает одну плитку (больше, если программа не может быть такой маленькой).
- **Отдалитесь**, чтобы видеть больше плиток сразу, **приблизьтесь**, чтобы видеть меньше.
  Окна получают новый размер, поэтому ими удобно пользоваться при любом масштабе.
- **Перемещайтесь** по стене, чтобы добраться до соседних окон.
- **Нажмите одну Logo**, чтобы увидеть все окна сразу ([обзор](#обзор)).

Нужны две программы рядом? Поставьте их в соседние плитки и отдалитесь. Снова нужна
только одна? Приблизьтесь обратно.

## Два окна на одном экране

Откройте вторую программу (она встанет рядом с первой) и нажмите **Logo+S**: окна поделят
экран пополам. Ещё раз Logo+S — каждое снова на весь экран. Другой способ: отдалите вид
(Logo+−), чтобы видеть два на два, и растяните окна Logo+Ctrl+стрелки.

## Клавиши

«Logo» — клавиша с логотипом Windows или Super. **Logo+/** показывает их все на экране
(любая клавиша или щелчок закрывает).

| Клавиши | Что делают |
|---|---|
| Logo+/ | все клавиши с описанием |
| Logo+Return | открыть терминал |
| Logo+D | лаунчер |
| Logo+H / J / K / L (или стрелки) | окно слева / ниже / выше / справа |
| Logo+Tab, Logo+Shift+Tab | все окна по очереди |
| Logo+T | следующее окно стопки (окна на одних и тех же плитках) |
| Logo (нажать отдельно) | обзор: все окна сразу |
| Logo+− / Logo+= (или U / N) | отдалить (видно больше окон) / приблизить |
| Logo+0 | вписать: окно на весь экран |
| Logo+S | **два окна рядом** на одном экране (окно в фокусе и его сосед), и обратно |
| Logo+Shift+H / J / K / L (или стрелки) | переместить окно по стене |
| Logo+Ctrl+H / J / K / L (или стрелки) | сделать окно уже / выше / ниже / шире, по плиткам |
| Logo+Q | закрыть окно |
| Logo+F | полный экран и обратно |
| Logo+Shift+V | окно плавает над стеной и обратно |
| Logo+V | история буфера обмена |
| Logo+Shift+S, Print | снимок экрана: выбрать, что снять |
| Logo+Print | снимок всего экрана, сразу |
| Alt+Print | снимок окна, сразу |
| Logo+P | заблокировать экран |
| Logo+Shift+C | перечитать конфигурацию |
| Logo+Shift+Escape | выйти из сеанса |
| Клавиши яркости, громкости, звука, микрофона | работают, в том числе на экране блокировки |
| Клавиши «играть», «дальше», «назад» | управляют плеером (через playerctl) |
| Клавиша дисплея (F7 на многих ноутбуках) | как использовать второй монитор: дублировать или расширить |
| Ctrl+Alt+F1 ... F12 | текстовые консоли |

Сочетания работают при любой раскладке: Logo+D на русской раскладке — тоже Logo+D.
Клавиатуру получает окно под мышью (щёлкать не нужно); `input { focusFollowsMouse = false }`
это выключает.

Любую из них можно изменить, словами: `bind("Super+Backspace", "close-window")` — см. [Клавиши](keys.md).

## Тачпад

| Пальцы | Что делают |
|---|---|
| три, в любую сторону | перемещение по стене |
| четыре, вверх / вниз | отдалить / приблизить |
| пять | лаунчер |
| зажатая Logo + нажать и тянуть | переместить окно |
| зажатая Logo + два пальца | изменить размер окна в фокусе |

Один и два пальца остаются за вашими программами (щелчки, прокрутка). Пока идёт жест,
короткая подсказка внизу экрана говорит, что он делает.

## Мышь с Logo

- **Logo + тянуть левой кнопкой** двигает окно под указателем, где угодно: на стене, в
  обзоре, плавающее окно.
- **Logo + тянуть правой кнопкой** меняет его размер.

Logo и простое движение мыши ничего не делают (`mouse { superMove = "motion" }` возвращает
поведение старого newm, где окно двигалось так).

## Обзор

Нажмите одну **Logo**: видны все окна сразу, маленькими.

- Окна в обзоре не получают щелчков: **щелчок выбирает окно**, и обзор заканчивается на нём.
- Выбранным считается окно под указателем: у него рамка фокуса. Нажмите Logo ещё раз — и
  обзор закончится на этом окне.
- **Logo + тянуть левой кнопкой** двигает окно прямо там, **Logo + тянуть правой** — меняет
  размер.
- **Logo+Shift+S** в обзоре снимает несколько окон целиком (см. [Снимки экрана](#снимки-экрана)).

## Размеры

- **Logo+Ctrl+стрелки** увеличивают или уменьшают окно на целые плитки; окно ложится поверх
  соседей, и получается стопка (Logo+T перебирает её). С `view { resizePushes = true }` соседи
  раздвигаются. Окно в одну плитку, сделанное уже, становится шириной в две, вытягиваясь
  влево, — как в newm.
- Программа, которая не может быть такой маленькой, как её плитка, сохраняет свой наименьший
  размер и рисуется уменьшенной, чтобы поместиться в плитку.
- Масштаб (Logo+−/=, четыре пальца) показывает больше или меньше плиток; программы получают
  новый размер, когда масштаб встаёт на целые плитки.

## Где открываются окна

- Новое окно открывается **рядом с тем, в котором вы**, на свободном месте, при котором окна
  остаются плотно и ближе к квадрату (третье окно встаёт под вторым, а не в конец длинного
  ряда), а вид сдвигается меньше всего; ничего не сдвигается, если рядом с вашим есть свободное
  место. `windows { newPlacement = "right-of-focused" }` открывает его справа от вашего, а окна
  правее сдвигаются на плитку; `"original"` возвращает поведение newm: первая свободная плитка в виде.
- Дочернее окно программы — диалог, выбор файла, просмотр фото — открывается **под её окном**
  (на свободное место там, иначе что ниже, сдвигается вниз). Окно без родителя тоже считается дочерним, если его открыла
  программа окна в фокусе (просмотр фото Telegram). `windows { childPlacement = "over" }`
  вместо этого показывает его плавающим поверх окна, как в newm; `"right"` ставит рядом.
- При закрытии дочернего окна фокус возвращается его окну.

Всё это: [Все настройки](settings.md#windows-).

## Плавающие окна

**Logo+Shift+V** снимает окно со стены: оно плавает над ней, и Logo + тянуть двигает его.
Некоторые программы (mpv, pavucontrol, калькулятор) плавают по правилу, окна постоянного
размера — сами. Плавающее окно сохраняет размер, который просит программа; программа, не
просящая никакого, открывается наименьшей.

## Полный экран

**Logo+F** или кнопка самой программы (у видео). Панель уходит. Logo+F ещё раз — обратно.

## Лаунчер

**Logo+D**, пять пальцев или кнопка меню на панели (три полоски, слева). Наберите несколько
букв, Enter запускает первую программу; стрелки или указатель выбирают другую. Без текста
он показывает программы, которые вы запускаете чаще всего, а потом все. Escape или Logo+D
закрывает его.

## Панель

Острова у верхнего края: окно, часы, трей и состояние компьютера. Каждый открывает
окошко по щелчку. Всё о ней — в [Панелях](bars.md). Коротко:

- **часы**: календарь;
- **Wi-Fi**, **Bluetooth**, **звук**, **батарея**: их окошки;
- **быстрые настройки** (сетка из четырёх квадратов перед кнопкой питания): яркость, Wi-Fi,
  Bluetooth, кофеин (экран не гаснет), светлая или тёмная тема, снимок экрана, история
  буфера, цвета, подсказка по клавишам и энергосбережение;
- кнопка **питания**: заблокировать, сон, гибернация, выйти, перезагрузка, выключить.
  Последние три переспрашивают.

## Светлая или тёмная

Плитка с солнцем и луной в быстрых настройках переключает newm и ваши программы между
светлой и тёмной темой. Выбор запоминается до следующего запуска (пока вы не выбрали —
тёмная). Закрепить в конфигурации: `colorScheme = "light"`.

## Снимки экрана

**Logo+Shift+S** или **Print** открывает выбор. Экран замирает: обведите рамкой нужную часть
(окно выбирается клавишей W или кнопкой на панели, а не тем, где оказался указатель). Внизу
панель инструментов:

| Вид | Клавиша | Что |
|---|---|---|
| Область | A или R | обведите рамку; потом двигайте её или тяните за края |
| Окно | W | щёлкните окно |
| Экран | S | весь монитор |
| Окна целиком | G | только в обзоре: несколько окон, каждое целиком |

Enter или пробел снимает; Ctrl+C только копирует; Escape закрывает. P добавляет на снимок
курсор, T ставит таймер, Tab перебирает виды, M переключает: двигать рамку или рисовать новую
при каждом движении. Стрелки двигают рамку (Shift — по 10 пикселей, Ctrl — меняют размер).
Каждая кнопка называет себя и свою клавишу, когда на неё наведён указатель.

**Logo+Print** сразу снимает экран, **Alt+Print** — окно.

**В обзоре** выбор начинается с «Окна целиком»: обведите окна рамкой (на снимок попадает
целиком каждое окно, которого она касается) или щёлкайте окна, чтобы добавить или убрать их;
Shift добавляет рамку к уже выбранным, Ctrl+A берёт все. Снимок собирается из окон в их
настоящем размере, чётким, на тех местах, где они стоят в обзоре, поверх обоев.

Снимки сохраняются в `~/Pictures/Screenshots` и копируются в буфер. Об этом скажет короткое
сообщение.

## История буфера обмена

**Logo+V** показывает, что вы недавно копировали: тексты, картинки и файлы, новое сверху.

- Набирайте текст для поиска. Enter или щелчок снова копирует запись; Delete удаляет её.
- Ctrl+P закрепляет запись: закреплённые всегда сверху и не вытесняются.
- Tab переходит между частями окна (поиск, виды: Все / Текст / Картинки / Закреплённые,
  список, «Очистить»); стрелки или h j k l двигают внутри части.
- «Очистить» удаляет всё, кроме закреплённого; стрелка рядом очищает только один вид.

История хранится только в памяти (кроме закреплённых текстов), и ничего из менеджеров
паролей (KeePassXC, Bitwarden, 1Password) в неё не попадает.

## Блокировка, бездействие и сон

- **Logo+P** блокирует экран (или «Заблокировать» в меню питания). Введите пароль и нажмите Enter.
- Без действий экран блокируется через 5 минут, экраны гаснут через 5½, а компьютер засыпает
  через 10. Программы, которые не дают экрану гаснуть (видеоплеер), откладывают это; так же
  действует **кофеин** в быстрых настройках (30 минут, час, два или пока не выключите).
- После сна экран заблокирован.

## Сообщения

- **Карточки** в правом верхнем углу, под панелью, в цветах панели: собственные сообщения
  newm (ошибка в конфигурации, приветствие). Для уведомлений программ нужна программа
  уведомлений, например mako или dunst (см. [Панели](bars.md#другие-панели)).
- **Уровни** внизу: громкость и яркость, когда они меняются.
- **Карточка посередине**, на мгновение: Wi-Fi, кабель или устройство Bluetooth подключились
  или отключились.

## Несколько мониторов

У каждого монитора своя стена. Указатель переходит с одного на другой. Монитор, впервые
подключённый, используется рядом с экраном ноутбука, и показывается выбор: дублировать,
расширить, только ноутбук, только другой. Клавиша дисплея (F7 на многих ноутбуках) или
`newm cmd displays mirror` (или `extend`, `laptop`, `other`) меняет это потом.

## Выход

**Logo+Shift+Escape** или «Выйти» в меню питания. Из другой консоли (Ctrl+Alt+F3) newm
завершает и `pkill newm`.

## Отличия от исходного newm

Управление окнами — как в исходном newm (на Python, jbuchermn/newm): та же сетка из целых
плиток, тот же масштаб, свайпы, прилипание, обзор, полный экран и алгоритм размещения.
Отличия, сделанные намеренно:

- **Экраны** (`screens { }`, включены по умолчанию): стена состоит из целых экранов, на
  каждом `windowsPerScreen` окон (2), разложенных раскладкой (столбцы; rows, grid, master,
  dwindle, monocle, ...); следующее окно открывается на следующем экране, а вид двигается
  только на целые экраны. Под панелями видны только панели (`windowsUnderBar`). `screens {
  enabled = false }` — свободная стена плиток, как в оригинале; всё ниже относится к ней.
- **Где открываются новые окна**: рядом с окном в фокусе, там, где стена остаётся плотной,
  ничего не сдвигается (в исходном: первая свободная плитка в виде) — для прежнего
  `windows { newPlacement = "original" }`.
- **Дочерние окна** (диалоги, просмотр) встают в плитку под своим окном, а при закрытии фокус
  возвращается ему (в исходном каждое окно с родителем плавало посередине него) — для
  прежнего `windows { childPlacement = "over" }`. Окно программы в фокусе без родителя
  считается её дочерним (`childBySameApp`).
- **Переход между окнами из диалога** начинается от его окна (в исходном — от угла стены), а
  фокус на диалоге держит его окно на виду.
- **Двигать и менять размер — Logo + кнопка мыши** (левая: двигать, правая: размер) вместо
  Logo и одной мыши (для прежнего `mouse { superMove = "motion" }`); в обзоре окна не получают
  щелчков — щелчок выбирает окно.
- При изменении размера соблюдается **наибольшая высота** окна (в исходном там бралась
  наименьшая ширина: описка).
- **Панели слева или справа** экрана тоже оставляют себе место.
- Выход из полного экрана сдвигом или масштабом сообщает программе, что она больше не в полном экране.
- Дополнения, ничего не меняющие по умолчанию: `view { fillFirst, resizePushes, crispResize,
  fitDrawnSize, fade, unfocusedOpacity }`, `fitFocusedView` (Logo+0), `sideBySide` (Logo+S),
  особые рабочие пространства, scratchpad'ы, панель, экран блокировки, лаунчер, уведомления,
  буфер обмена, снимки экрана, анимации по имени и автозапуск.

Убрано: более мелкая сетка прежнего newm на Kotlin (окно в одну плитку, делившееся на 2 × 2
меньших и обратно) с настройками `minSizeKeepsShape` и `minSizeShrink` (они ещё принимаются,
но ничего не делают). Она работала плохо; лучший способ делать окна меньше появится позже.
