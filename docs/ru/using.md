# Каждый день

[English](../en/using.md) · **Русский**

## Стена

Большинство оконных менеджеров размещают окна на экране. newm размещает их на бесконечной
**стене** из плиток, а экран показывает её часть:

```
   ┌────────┬────────┬────────┐
   │ editor │ terminal        │      ← окно занимает одну плитку или несколько
   ├────────┼────────┼────────┤
   │ browser         │ music  │
   └────────┴────────┴────────┘
        экран показывает 2×2 плитки; отдалитесь, чтобы увидеть больше
```

- Новое окно занимает следующую свободную плитку.
- **Отдалитесь**, чтобы видеть больше плиток сразу, **приблизьтесь**, чтобы видеть меньше.
  Окна получают новый размер, поэтому ими удобно пользоваться при любом масштабе.
- **Перемещайтесь** по стене, чтобы добраться до соседних окон.
- **Нажмите одну Logo**, чтобы увидеть все окна сразу (обзор).

Нужны две программы рядом? Поставьте их в соседние плитки и отдалитесь. Снова нужна
только одна? Приблизьтесь обратно.

## Два окна на одном экране

Откройте вторую программу (она встанет рядом с первой) и нажмите **Super+S**: окна поделят
экран пополам. Ещё раз Super+S — каждое снова на весь экран. Другой способ: отдалите вид
(Super+−), чтобы видеть два на два, и растяните окна Super+Ctrl+стрелки.

## Клавиши

| Клавиши | Что делают |
|---|---|
| Super+/ | **все клавиши** с описанием (любая клавиша закрывает) |
| Super+Return | открыть терминал |
| Super+D | лаунчер: наберите пару букв, Enter запускает; Super+D ещё раз или Escape закрывает |
| Super+H / J / K / L (или стрелки) | окно слева / ниже / выше / справа |
| Super+Tab, Super+Shift+Tab | все окна по очереди |
| Super (нажать отдельно) | обзор: все окна сразу |
| Super+S | **два окна рядом** на одном экране (окно в фокусе и его сосед), и обратно |
| Super+0 | вписать: окно на весь экран |
| Super+− / Super+= (или U / N) | отдалить (видно больше окон) / приблизить |
| Super+Shift+H / J / K / L (или стрелки) | переместить окно по стене |
| Super+Ctrl+H / J / K / L (или стрелки) | сделать окно уже / выше / ниже / шире, по плиткам |
| Super+F | полный экран и обратно |
| Super+V | окно плавает над стеной и обратно |
| Super+Q | закрыть окно |
| Super+P | заблокировать экран |
| Super+Shift+Escape | выйти из сессии |
| Клавиши яркости, громкости и звука | работают, в том числе на экране блокировки |

Сочетания работают при любой раскладке: Super+D на русской раскладке — тоже Super+D.
Клавиатуру получает окно под мышью (кликать не нужно); `input { focusFollowsMouse = false }` это выключает.

Любую из них можно изменить: см. [Ваша конфигурация](configuration.md#клавиши).

## Тачпад

| Пальцы | Что делают |
|---|---|
| три, в любую сторону | перемещение по стене |
| четыре, вверх / вниз | отдалить / приблизить |
| пять | лаунчер |
| зажатая Logo + один палец (или мышь) | переместить активное окно |
| зажатая Logo + два пальца | изменить его размер |

Один и два пальца остаются за вашими программами (щелчки, прокрутка).

## Экран блокировки и лаунчер

- **Logo+p** блокирует экран. Введите пароль и нажмите Enter.
- **Logo+d** (или пять пальцев) открывает лаунчер. В нём список установленных программ:
  наберите несколько букв и нажмите Enter.
