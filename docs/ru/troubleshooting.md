# Если что-то пошло не так

[English](../en/troubleshooting.md) · **Русский**

- **Карточка-уведомление вверху сообщает об ошибке в конфигурации.** В ней указаны файл
  и строка. Исправьте строку и сохраните файл — карточка исчезнет. До тех пор newm работает
  с прежними, рабочими настройками.
- **Журнал**: `~/.local/state/newm/newm.log`; журнал предыдущего запуска — в `newm.log.old`.
  Чтобы получить больше подробностей, запустите newm так: `CAULIS_LOG=3 newm`.
- **Всё зависло?** Logo+Shift+Escape завершает сеанс. Из другой консоли (Ctrl+Alt+F3)
  newm можно завершить командой `pkill newm`.
- **Программа не открывается или сразу закрывается.** Возможно, это программа X11:
  установлен ли `xorg-xwayland`? Запустите её из терминала внутри newm и посмотрите, что она пишет.
- **Не работает демонстрация экрана или окно выбора файлов.** Установите `xdg-desktop-portal`
  и `xdg-desktop-portal-gtk` (или `-wlr`). newm сам передаёт им своё окружение.
- **newm нет на экране входа.** Выполните `newm install-session`.
- **В терминале крошечный текст.** Размер шрифта определяет сам терминал. Для foot задайте
  его в `~/.config/foot/foot.ini` (`font=monospace:size=11`); Ctrl+= меняет размер только
  в одном окне. На экране с высокой чёткостью `output("eDP-1") { scale = 1.25 }` сделает
  всё крупнее.
- **Программа-панель перекрывает окна.** Скорее всего, она не резервирует под себя место
  (исключительная зона, exclusive zone). В waybar за это отвечает `"exclusive": true` —
  это его значение по умолчанию.
- **Что-то другое?** Создайте issue и приложите журнал:
  https://github.com/AristarkhKenebas/newm/issues
