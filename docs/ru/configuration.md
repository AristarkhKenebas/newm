# Ваша конфигурация

[English](../en/configuration.md) · **Русский**

Ваша конфигурация — файл `~/.config/newm/config.kts`. newm записывает его при первом запуске,
с пояснением к каждой настройке. Это Kotlin, но знать это почти не нужно: это список
разделов с настройками внутри.

```kotlin
view {
    cornerRadius = 14.0     // скруглённые окна
    padding = 8.0           // отступ вокруг каждого окна
}
```

- `// ...` — пояснение. Уберите `//` в начале строки, чтобы она заработала.
- Дробные числа пишутся через точку: `8.0`.
- Текст пишется в кавычках: `"alacritty"`. Цвета — `"#RRGGBB"` или `"#RRGGBBAA"`, где две
  последние цифры задают прозрачность (`00` — невидимый, `FF` — сплошной).
- Настройка, которую вы не указали, берёт значение newm по умолчанию. [Все настройки](settings.md)
  перечисляет их со значениями по умолчанию; `newm cmd config` выводит те, что действуют сейчас.

## Сохранение и ошибки

- **Сохранение** сразу применяет файл. Чтобы попробовать изменение, выходить из сеанса не
  нужно. **Logo+Shift+C** перечитывает его вручную.
- **Ошибка** (опечатка, пропущенная кавычка) появляется карточкой в правом верхнем углу, с
  файлом и строкой: `config.kts:42: Unresolved reference ...`. newm оставляет рабочие
  настройки, пока вы не сохраните файл без ошибки. Значение не того вида (слово там, где нужно
  число) пропускается, и карточка говорит, какое.
- **Сломанный файл при запуске** никогда не даёт чёрный экран. newm запускается со своей
  стартовой конфигурацией и показывает, что не так.
- **Запутались?** Переименуйте или удалите папку `~/.config/newm`. Следующий запуск запишет
  новую.

Первая загрузка после запуска занимает несколько секунд (Kotlin компилируется); следующие
сохранения быстрее.

### Какой файл

newm читает **один** файл из `~/.config/newm/`, первый найденный: `config.kts`, `config.lua`,
`config.json`, `config.py` (см. [другие форматы](other-formats.md)).

Если там ничего нет, newm создаёт папку: копию `/etc/newm/`, если она есть в системе (её
`config.kts`, `config.lua` или `config.json`; `programs.newm.settings` в NixOS пишет туда
`config.json`), иначе свой `config.kts`. Это происходит один раз: дальше папка ваша, и
изменения в `/etc/newm` до неё не доходят.

## Рецепты

### Свои обои

```kotlin
background { path = "~/Pictures/wallpaper.jpg" }
```

SVG тоже подходит (`wallpaper.svg`): он остаётся чётким при приближении.

По умолчанию обои двигаются и масштабируются вместе с видом, а в обзоре их видно больше.
Чтобы они стояли на месте:

```kotlin
background { mode = "static" }   // "follow" (по умолчанию)
```

### Раскладки клавиатуры

Без этой настройки newm берёт раскладки системы: те, что задал `localectl set-x11-keymap`,
а если их нет — раскладку вашего языка рядом с английской (с `LANG=ru_RU` — «us,ru»), с
переключением по Alt+Shift. Панель показывает текущую раскладку (EN, RU); щелчок по ней тоже
переключает. Свои:

```kotlin
keyboard {
    layouts = "us,ru"
    options = "grp:alt_shift_toggle"    // или "grp:win_space_toggle": Logo+Space, "grp:caps_toggle": Caps Lock
    // variants = ",phonetic"           // по одному на раскладку
    // numLock = true                   // Num Lock включён с самого начала
}
```

Изменение применяется сразу после сохранения. Переключать может и своя клавиша:
`keys { "L-S-space" { caulis.run("keyboard-layout next") } }`.

### Клавиши

```kotlin
bind("Super+Backspace", "close-window")      // закрывать окно и по Super+Backspace
bind("Super+B", "launch", "firefox")
unbind("Super+S")                            // клавиша шаблона убрана
keys {
    "Super+E"("Файлы") { launch("nautilus") }   // со своим кодом
}
```

Клавиши пишутся, как вы их называете (`"Super+Shift+Q"`, `"Ctrl+Alt+T"`, регистр не важен;
Super — это и Logo, Win, Mod, Meta), действия — по имени (`close-window`, `launch`,
`fullscreen`, ...). Прежняя запись newm (`"L-q"`, `"L-S-h"`) тоже работает. Все имена клавиш
и действий и готовые наборы: [Клавиши](keys.md). `newm cmd keys` перечисляет назначенные клавиши.

### Одни окна плавают, у других размытие

```kotlin
view {
    rules { view ->
        when (view.appId) {
            "mpv", "pavucontrol" -> rule(float = true)
            "wlogout" -> rule(float = true, floatSize = 1920 to 1080, floatPos = 0.5 to 0.5)
            "Alacritty" -> rule(blur = Blur(radius = 6, passes = 4))
            "catapult" -> rule(focus = false)     // без рамки фокуса
            else -> null
        }
    }
}
```

Чтобы узнать app id окна, откройте его и выполните в терминале `newm cmd debug`. Команда
перечислит все окна с их id. `view.title` — заголовок окна, если он нужен.

Размытие видно только за полупрозрачными окнами. Сделайте фон терминала полупрозрачным в
его собственных настройках (в alacritty: `window.opacity = 0.85`).

### Программы при запуске

```kotlin
onStartup {
    launch("mako")
    launch("nm-applet --indicator")
}
```

### Панель

У newm есть своя панель, и любая другая тоже работает (waybar, ...). Можно обойтись и вовсе
без панели. См. [Панели](bars.md).

### Мониторы

```kotlin
output("eDP-1") { scale = 1.25 }
output("HDMI-A-1") { width = 2560; height = 1440; refreshHz = 144.0; x = 1920; y = 0 }
output("DP-2") { transform = 1 }   // повёрнут на 90°
```

Названия мониторов покажет `newm cmd debug` (они в «Outputs» каждого рабочего пространства).

### Блокировка и сон при бездействии

```kotlin
energy {
    idleTimes = listOf(120, 300, 600)   // секунды: «простой», блокировка, сон (см. ниже)
    screensOffAfter = 330               // экраны гаснут; клавиша или мышь возвращают их (0: никогда)
    suspendCommand = "systemctl suspend"
}
lockOnWakeup = true                     // после сна экран заблокирован
```

О первом сроке только сообщается в `onIdle` (сам newm тогда ничего не показывает; ваш
сценарий может, например, притушить экран), второй блокирует, третий усыпляет компьютер.
Каждый шаг происходит один раз; когда вы возвращаетесь, всё начинается заново. Программы,
которые не дают экрану гаснуть (видеоплеер), откладывают это. Короткий список убирает
последние шаги: `idleTimes = listOf(120, 300)` блокирует, но никогда не усыпляет компьютер.

То же по отдельности, с 0 — «никогда», и свои шаги:

```kotlin
energy {
    dimAfter = 120          // «простой» сообщается в onIdle
    lockAfter = 0           // сам не блокирует
    suspendAfter = 1800     // засыпает через полчаса
    after(900) { launch("playerctl pause") }   // своё, один раз, пока вы не вернётесь
}
```

```kotlin
val brightness = { how: String -> launch("brightnessctl $how") }
energy {
    onIdle { what ->            // "idle", "idle-lock", "idle-presuspend", "idle-suspend", "active", "sleep", "wakeup"
        if (what == "idle") brightness("-s set 30%")     // притушить и запомнить яркость
        if (what == "active") brightness("-r")          // вернуть как было
    }
}
```

### Кофеин

В быстрых настройках есть «Кофеин»: его квадрат не даёт экрану гаснуть (ни блокировки, ни
отключения экрана, ни сна), пока вы его не выключите; его надпись предлагает 30 минут, час или
два. Пока он включён, на панели видна чашка. Из терминала: `newm cmd caffeine 45`,
`newm cmd caffeine on`, `newm cmd caffeine off`. Пока работает `newm cmd inhibit-idle` — то же
самое. Другие сроки: `caffeine { choices = listOf(15, 45, 90, 0) }` (минуты; 0 — пока не
выключите).

### Свой экран блокировки

У newm свой экран блокировки. Чтобы вместо него использовать swaylock, gtklock или hyprlock:

```kotlin
panels {
    lock { program = "swaylock -f -c 2E3440" }
}
```

Тогда Logo+P и блокировка при бездействии запускают его.

Свой экран блокировки newm берёт цвета панели (светлые или тёмные, как всё); свои цвета и
часы:

```kotlin
lock {
    background = "#2E3440EE"; text = "#ECEFF4"; accent = "#88C0D0"   // прежний вид Nord
    clock = "HH:mm:ss"          // не задано: timeFormat ("HH:mm")
    date = "EEEE, d MMMM"       // "" — без даты
}
```

### Лаунчер

```kotlin
launcher {
    width = 720; height = 560; top = 0.16   // пиксели; верх — доля высоты экрана
    frequent = 6                // самые запускаемые программы первыми (0: нет)
    remember = true             // false: не записывать, что вы запускаете
    hide = listOf("htop", "org.gnome.Extensions")   // по имени или id .desktop
    runTyped = true             // Enter, когда ничего не нашлось, запускает набранное
    entries {
        "Заблокировать"("Заблокировать экран") { ensureLocked() }
        "Выйти" { terminate() }
    }
    keys { "C-Return" { runTyped() } }   // next(), previous(), first(), last(), start(), runTyped(), close()
}
terminal = "foot"               // терминал для программ, которые работают в нём, и для "terminal"
```

Кроме стрелок, выбирают Ctrl+N / Ctrl+P, Ctrl+J / Ctrl+K и Tab / Shift+Tab.

### Курсор, тачпад и мышь

```kotlin
cursor { theme = "Adwaita"; size = 24; hideAfter = 5 }   // прятать через 5 с неподвижности
input {
    tapToClick = true
    naturalScroll = true
    focusFollowsMouse = true    // клавиатуру получает окно под указателем (false: по щелчку)
}
mouse { superMove = "button" }  // Logo + тянуть левой кнопкой двигает, правой — меняет размер;
                                // "motion": Logo и простое движение мыши двигают окно, как в старом newm
```

### Графический планшет

Планшет работает сразу: перо — это курсор везде (касание — щелчок, кнопки на пере — правая и
средняя), а программы, которые знают о планшетах — Krita, GIMP, Inkscape, — получают нажим,
наклон пера и остальное. Как он ложится на экраны:

```kotlin
input {
    tablet {
        monitor = "eDP-1"           // монитор, который он покрывает (не задан: у экрана с пером свой, у других все как один)
        keepAspect = true           // форма монитора сохраняется: полоса планшета не используется
        area(0.0, 0.0, 0.8, 0.8)    // только часть планшета (доли, от левого верхнего угла)
        leftHanded = false          // повёрнут для левой руки
        pointerOnly = false         // true: без нажима и наклона для программ, перо как мышь
        tipPressure = 0.05          // насколько сильно нажать для касания (не задано: как решит libinput)
        lowerButton = "right"; upperButton = "middle"; thirdButton = "side"   // или "left", "extra", "none"
    }
}
```

Кнопки самого планшета (пэд) идут программе с клавиатурой.

### Обзор

```kotlin
overview {
    input = false          // true: окна в обзоре получают щелчки, как в старом newm
    choose = true          // щелчок выбирает окно и заканчивает обзор
    followPointer = true   // выбранное окно — то, что под указателем (его рамка, Logo + тянуть)
}
```

### Как окна выглядят и ведут себя

```kotlin
view {
    cornerRadius = 14.0
    padding = 8.0
    unfocusedOpacity = 0.9       // окна без фокуса немного прозрачные
    fade = true                  // окна плавно появляются и исчезают
    fillFirst = false            // true: первое окно занимает весь экран (false: четверть, как в newm)
    resizePushes = false         // true: окно, увеличенное клавишами, раздвигает соседей
    crispResize = false          // true: окно при изменении размера рисуется в своём размере, не растягивается
    fitDrawnSize = false         // true: программа, нарисовавшая другой размер, вписывается в своей форме
    floatingMinSize = true       // плавающее окно, не просящее размера, открывается наименьшим
}
windows {
    newPlacement = "right-of-focused"  // или "beside-focused", "end", "original" (как в newm)
    childPlacement = "below"           // диалог, просмотр фото: "below" — под своим окном, "right", "over" (плавает, как в newm)
    returnFocusToParent = true         // при закрытии фокус возвращается его окну
}
focus {
    color = "auto"               // акцент цветов; или "#RRGGBB" / "#RRGGBBAA"
    width = 2.0; distance = 4.0
}
```

### Светлая или тёмная, и цвета

Светлая или тёмная тема — для панели, меню, лаунчера, экрана блокировки и ваших программ
вместе — переключается в быстрых настройках и запоминается до следующего запуска
(`~/.local/state/newm/color-scheme`; пока не выбрано — тёмная). Закрепить:

```kotlin
colorScheme = "dark"   // "auto" (последний выбор в быстрых настройках, по умолчанию), "dark" или "light"
```

Цвета панели, меню и рамки фокуса берутся из обоев. Плитка с палитрой в быстрых настройках
выбирает среди них; закрепить:

```kotlin
colors {
    source = "wallpaper"   // "wallpaper", "nord" (классические цвета newm) или цвет: "#5b8cc8"
    style = "tonal"        // "tonal", "vibrant", "expressive", "neutral", "monochrome"
}
```

`newm cmd colors` говорит, какие цвета сейчас; `newm cmd colors nord` меняет их.

### Язык

Меню newm говорят по-русски, если язык системы русский. Выбрать:

```kotlin
language = "en"     // "auto" (язык системы, по умолчанию), "en" или "ru"
```

### Снимки экрана

Клавиши — в `keys { }` (Logo+Shift+S и Print: выбор; Logo+Print: экран; Alt+Print: окно).
Как работает выбор — в [Каждый день](using.md#снимки-экрана).

```kotlin
screenshots {
    enabled = true
    folder = "~/Pictures/Screenshots"
    save = true; copy = true        // в файл, в буфер обмена
    pointer = false                 // курсор на снимке
    toast = true                    // «Снимок сохранён» на мгновение
    start = "region"                // выбор начинается с "region", "window" или "screen" (не задано: последний)
    delay = 0                       // секунд до снимка
    selection = "adjust"            // область: "adjust" (обвести, потом двигать и тянуть) или "new" (каждый раз новая)
    overviewStart = "windows"       // в обзоре: "windows" (несколько, целиком), "region", ... или "" (последний)
    sharpWindows = true             // область в обзоре собирается из окон, чёткой
    sharpBackground = "wallpaper"   // за ними: "wallpaper", "none" (прозрачно), "#RRGGBB", "theme"
    fileName = "Screenshot from {date} {time}"   // {date}, {time}, {kind}
    format = "png"; quality = 92    // или "jpg"
    then = "satty --filename {file}"            // команда для каждого файла (редактор)
}
```

### История буфера обмена

```kotlin
clipboard {
    enabled = true                  // false: ничего не хранится, Logo+V ничего не делает
    size = 50                       // сколько записей хранить (закреплённые — сверх этого)
    pictures = true; files = true   // картинки и скопированные файлы тоже
    keepPins = true                 // закреплённые тексты переживают перезапуск (~/.local/state/newm/clipboard-pins.json)
    ignore = listOf("keepassxc", "bitwarden", "1password")   // из этих программ — никогда
    maxPictureMb = 16; maxText = 200000
    clearAtOnce = true              // false: «Очистить» сначала спрашивает
    onChoose = "copy"               // "paste": ещё и вставить в ваше окно (Ctrl+V; в терминале Ctrl+Shift+V)
    width = 980; height = 620; top = 0.13
    pinKey = "C-p"
}
```

### Уведомления

newm сам служит сервером уведомлений (org.freedesktop.Notifications): сообщения Telegram,
законченная загрузка, низкий заряд приходят карточками справа вверху, под панелью, в её
цветах. Карточка держится несколько секунд (пока над ней указатель, она ждёт; критические —
пока их не закроют); щелчок по ней открывает её программу и выполняет главное действие,
её кнопки — свои, × закрывает её. Пока экран заблокирован или окно во весь экран, карточки
не показываются: уведомления всё равно попадают в историю за колокольчиком на панели.

История умная: стоит несколько секунд посмотреть на окно программы (беглый взгляд не
считается) — её уведомления прочитаны и уходят из истории; старые уходят сами.

```kotlin
notifications {
    enabled = true                  // false: newm оставляет уведомления другому демону (mako, dunst, swaync)
    seconds = 6                     // сколько держится карточка, если программа не сказала
    doNotDisturb = false            // true: без карточек, только история (переключатель у колокольчика тоже)
    readAfterFocusSeconds = 3       // окно программы в фокусе столько секунд — её уведомления прочитаны
    keepHours = 24; keep = 100      // старше или больше — уходят из истории
    remember = true                 // история переживает перезапуск (~/.local/state/newm/notifications.json)
    takeOver = "stale"              // демон от старой сессии закрывается ("always", "never")
    corner = "top_right"            // "top_left", "top", "bottom_right", "bottom_left", "bottom" (сообщения композитора следуют)
    width = 380; gap = 10           // ширина карточек, промежуток между ними и до края
    maxCards = 3                    // сколько сразу: самая старая уходит в историю
    monitor = "focused"             // "pointer", "first" или имя монитора ("eDP-1")
    criticalSeconds = 0             // сколько держится критическое (0: пока не закроют)
    showInFullscreen = false        // true: карточки и поверх окна во весь экран
    // Правила, по очереди: mute() без карточки (только история), hide() не хранить вовсе, urgency(0..2), seconds(n)
    rule { n -> if (n.app == "Spotify") mute() }
    rule { n -> if (n.summary.contains("пароль", ignoreCase = true)) hide() }
    onNotification { n -> println("${n.app}: ${n.summary}") }   // о каждом (после правил)
}
timeFormat = "HH:mm"                // как пишется время ("h:mm a"): история, экран блокировки, буфер обмена
```

В JSON и Lua правило — таблица: чему оно соответствует (`app`, `entry`, `summary`,
`app_matches`, `summary_matches`, `body_matches`: последние три — регулярные выражения) и что
оно говорит (`mute`, `hide`, `urgency`, `seconds`):

```json
"notifications": { "rules": [ { "app": "Spotify", "mute": true }, { "body_matches": "(?i)code: \\d+", "seconds": 30 } ] }
```

Если имя уже занято другим демоном (скажем, mako, оставшимся от другого сеанса), newm с ним
не спорит: один раз говорит «Уведомления уходят в mako — уведомления newm выключены» и
берёт имя, как только тот завершится.

### Звук и сообщения на экране

```kotlin
sound { maxVolume = 150 }           // верх ползунка громкости, в процентах (выше 100: усиление)
osd {
    connections = "cards"           // Wi-Fi, кабель, Bluetooth подключились или отключились: "cards", "text" (строка), "off"
    seconds = 1.3                   // сколько видна шкала громкости или яркости
    position = "bottom"             // где: "bottom", "top", "center"
    distance = 130                  // на таком расстоянии от края, в пикселях
    toastSeconds = 1.6              // короткое сообщение посередине
    cardSeconds = 2.8               // карточка подключения
    inFullscreen = false            // подключения и поверх окна во весь экран
    onConnection { e -> }           // о каждом (e.kind: WIFI, WIRED, BLUETOOTH; e.connected; e.name)
}
```

Шаг колеса громкости и яркости, их команды, уровни батареи и меню питания: см.
[Панели](bars.md#что-нужно-панели).

### Выпадающий терминал (scratchpad)

Окно отдельно от стены, которое одна клавиша показывает поверх всего и снова прячет, как
scratchpad в sway. Программа запускается при первом нажатии:

```kotlin
caulis.scratchpad("drop", command = "foot --app-id drop",
    style = dev.caulis.core.Scratchpad.Center(width = 0.7, height = 0.6))
keys {
    "L-grave"("Выпадающий терминал") { scratchpad("drop") }
}
```

Окна относятся к нему по app id (здесь «drop»). Другие виды: `Scratchpad.Edge()` выезжает
сверху (`Edge(side = Side.RIGHT)` — справа), `Scratchpad.Overlay()` — целое рабочее
пространство поверх текущего. Из терминала: `newm cmd scratchpad drop`.

### Проектор или второй монитор: дублировать или расширить

Монитор, подключённый впервые, используется рядом с экраном ноутбука, и показывается выбор
режимов; клавиша дисплея ноутбука (F7 на многих) показывает его в любой момент. Из терминала:
`newm cmd displays mirror` (одна картинка на обоих), `extend`, `laptop` или `other` (только
он). Выбор запоминается для этого монитора.

### Всё, что умеет Caulis

`caulis` в вашей конфигурации — библиотека композитора, на которой построен newm
([Caulis](https://github.com/AristarkhKenebas/caulis)). То, что описано в её руководстве,
работает и здесь — для того, на что у newm нет своей настройки.

## Перезапуск newm

`newm cmd restart` завершает newm и запускает его снова (это делает скрипт запуска newm, а
`dev/newm-dev` — с новой сборкой). Все программы закрываются, как при выходе из сеанса:
сначала сохраните работу. `newm cmd restart keep` ещё и сохраняет ваши окна: при следующем запуске каждая программа
запускается снова (терминал — в папке, где была его оболочка), и её окно возвращается на своё
место. То, что программа держала открытым внутри (вкладки, файлы), она возвращает сама.

```kotlin
session {
    restoreAtLogin = false      // true: окна прошлой сессии открываются снова при входе
    maxAgeMinutes = 10          // restart keep: запомненные раньше этого не открываются (0: без ограничения)
    maxWindows = 20             // не больше стольких программ; остальные предложит лаунчер
    exclude = listOf("steam")   // никогда не открывать снова (app id или программа)
    staggerMs = 300             // программы по очереди, а не все сразу
}
```

Под `dev/newm-dev` newm сразу запускается снова ([Разработка newm](development.md)). Если newm
был запущен с экрана входа или из консоли, он завершается, и вы возвращаетесь туда: запустите
его снова, и окна вернутся.

## Если экран мерцает

`newm cmd full-redraw on` рисует каждый кадр целиком (чуть медленнее), а
`newm cmd full-redraw off` возвращает как было. Если с ним мерцание пропало, напишите об этом в
отчёте об ошибке: оно происходит от рисования только изменившегося.
