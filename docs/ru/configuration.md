# Ваша конфигурация

[English](../en/configuration.md) · **Русский**

Ваша конфигурация — это файл `~/.config/newm/config.kts`. newm создаёт его при первом
запуске, с пояснением к каждой настройке. Файл написан на Kotlin, но знать это почти не
нужно: это просто список разделов, а в них — настройки.

```kotlin
view {
    cornerRadius = 14.0     // скруглённые окна
    padding = 8.0           // отступ вокруг каждого окна
}
```

- `// ...` — это пояснение. Уберите `//` в начале строки, чтобы включить то, что в ней написано.
- Дробные значения пишутся через точку: `8.0`.
- Текст пишется в кавычках: `"alacritty"`. Цвета — `"#RRGGBB"` или `"#RRGGBBAA"`, где
  последние две цифры делают цвет прозрачным (`00` — невидимый, `FF` — сплошной).

## Сохранение и ошибки

- **Сохранение** сразу применяет файл. Чтобы попробовать изменение, выходить из сеанса не нужно.
- **Ошибка** (опечатка, пропущенная кавычка) появляется карточкой-уведомлением вверху экрана,
  с именем файла и номером строки: `config.kts:42: Unresolved reference ...`. Пока вы
  не сохраните файл без ошибки, newm продолжает работать с прежними, рабочими настройками.
- **Сломанный файл при запуске** никогда не даёт чёрного экрана. newm запускается со своими
  настройками по умолчанию и показывает, что не так.
- **Запутались?** Удалите папку `~/.config/newm`. При следующем запуске newm создаст новую.

Первое сохранение после запуска занимает несколько секунд (Kotlin компилируется один раз);
следующие проходят быстро.

Для всех пользователей компьютера стартовая конфигурация лежит в `/etc/newm/`: новые
пользователи получают её копию.

Вам ближе Lua, JSON или Nix? См. [другие форматы](other-formats.md).

## Рецепты

### Свои обои

```kotlin
background { path = "~/Pictures/wallpaper.jpg" }
```

`anim = false` делает их неподвижными (по умолчанию они слегка смещаются вместе с видом).
SVG тоже подходит (`wallpaper.svg`): такие обои остаются чёткими при приближении.

### Раскладки клавиатуры

Без этой настройки newm берёт раскладки системы: заданные через `localectl set-x11-keymap`,
а если их нет — раскладку вашего языка рядом с английской (при `LANG=ru_RU` — "us,ru"),
переключение — Alt+Shift. Панель показывает текущую раскладку (EN, RU), клик по ней тоже
переключает. Свои раскладки:

```kotlin
keyboard {
    layouts = "us,ru"
    options = "grp:alt_shift_toggle"    // или "grp:win_space_toggle": Super+Space, "grp:caps_toggle": Caps Lock
}
```

Изменение применяется сразу после сохранения. Переключать может и своя клавиша:
`keys { "L-S-space" { caulis.run("keyboard-layout next") } }`.

### Клавиши

```kotlin
keys {
    "L-b" { launch("firefox") }
    "L-S-s" { launch("grim -g \"$(slurp)\" ~/shot.png") }
}
```

Клавиши записываются так, как в newm было всегда:

- `L` — это Logo, `S` — Shift, `C` — Ctrl, `A` — Alt;
- `"L-S-s"` — это Logo+Shift+s, а заглавная буква тоже означает Shift (`"L-S"` — то же самое);
- `"L-"` — это одна нажатая Logo;
- `"L-a L-b"` — это Logo+a, а затем Logo+b.

Внутри `{ }` можно использовать всё, что умеет раскладка окон (`move(-1, 0)`, `toggleOverview()`, ...):
список — в разделе [Все настройки](settings.md#что-умеют-клавиши).

### Одни окна плавают, у других — размытие

```kotlin
view {
    rules { view ->
        when (view.appId) {
            "mpv", "pavucontrol" -> rule(float = true)
            "wlogout" -> rule(float = true, floatSize = 1920 to 1080)
            "Alacritty" -> rule(blur = Blur(radius = 6, passes = 4))
            else -> null
        }
    }
}
```

Чтобы узнать app id окна, откройте это окно и выполните в терминале `newm cmd debug`.
Команда выведет каждое окно с его id.

Размытие видно только за прозрачными окнами. Сделайте фон терминала прозрачным в его
собственных настройках (в alacritty: `window.opacity = 0.8`).

### Программы при запуске

```kotlin
onStartup {
    launch("mako")
    launch("nm-applet --indicator")
}
```

### Панель

У newm есть своя панель, но подойдёт и любая другая (waybar, ...). Можно обойтись и вовсе
без панели. См. [Панели](bars.md).

### Мониторы

```kotlin
output("eDP-1") { scale = 1.25 }
output("HDMI-A-1") { width = 2560; height = 1440; refreshHz = 144.0; x = 1920; y = 0 }
```

Чтобы узнать имена мониторов, выполните `newm cmd debug`.

### Затемнение, блокировка и сон при бездействии

```kotlin
energy {
    idleTimes = listOf(120, 300, 600)   // затемнить через 2 минуты, заблокировать через 5, уснуть через 10
    screensOffAfter = 330               // погасить экраны; клавиша или мышь их вернут
}
```

Каждый шаг срабатывает один раз; когда вы вернётесь, отсчёт начнётся заново. Программы,
которые держат экран включённым (видеоплеер), откладывают всё это.

### Свой экран блокировки

У newm есть свой экран блокировки. Чтобы вместо него был swaylock, gtklock или hyprlock:

```kotlin
panels {
    lock { program = "swaylock -f -c 2E3440" }
}
```

Тогда Logo+p и блокировка при бездействии запускают его.

### Курсор и тачпад

```kotlin
cursor { theme = "Adwaita"; size = 24; hideAfter = 5 }   // спрятать через 5 с без движения
input { tapToClick = true; naturalScroll = true }
keyboard { numLock = true }                              // Num Lock включён с самого начала
```

### Как выглядят окна

```kotlin
view {
    unfocusedOpacity = 0.9      // окна без фокуса чуть прозрачные
    fade = true                 // окна плавно появляются и исчезают (включено по умолчанию)
    fillFirst = true            // первое окно занимает весь экран (включено по умолчанию)
    rules { view ->
        if (view.appId == "catapult") rule(focus = false) else null   // без рамки фокуса
    }
}
```

### Светлые или тёмные программы

```kotlin
caulis.colorScheme = dev.caulis.core.appearance.ColorScheme.DARK
```

`caulis` — это библиотека для композиторов, на которой построен newm ([Caulis](https://github.com/AristarkhKenebas/caulis)).
Всё, что описано в её руководстве, работает и здесь — например, схема, которая меняется
в зависимости от времени суток.

### История буфера обмена

Super+V показывает, что вы недавно копировали: тексты и картинки, новые сверху. Начните печатать,
чтобы искать; Enter или щелчок копирует запись снова; Delete или её ✕ удаляет; «Очистить всё»
очищает историю. Она хранится только в памяти, на диск не пишется, а то, что менеджеры паролей
помечают как секрет, не сохраняется.

```kotlin
clipboard {
    enabled = true      // false: ничего не сохраняется, Super+V ничего не делает
    size = 50           // сколько записей хранить
}
keys {
    "L-v"("Clipboard history") { toggleClipboard() }   // или другая клавиша
}
```

### Кофеин

Во вкладке батареи есть «Кофеин»: экран не гаснет (без затемнения, блокировки и сна) 30 минут,
час, два или пока вы его не выключите. Пока он включён, на панели виден значок чашки. Из
терминала: `newm cmd caffeine 45`, `newm cmd caffeine on`, `newm cmd caffeine off`.

### Кнопка меню и язык

Панель начинается с кнопки из трёх полосок, она открывает меню программ. `bar { menuButton = false }`
её убирает; чтобы поставить её в другое место, добавьте `"menu"` в `left`, `center` или `right`.

Меню newm говорят по-русски, если язык системы русский. Выбрать язык явно:

```kotlin
language = "ru"     // "auto" (как в системе, по умолчанию), "en" или "ru"
```

### Scratchpad (выпадающий терминал)

Окно вне стены окон, которое одна клавиша показывает поверх всего и снова прячет, как
scratchpad в sway. Программа запускается при первом нажатии:

```kotlin
caulis.scratchpad("drop", command = "foot --app-id drop",
    style = dev.caulis.core.Scratchpad.Center(width = 0.7, height = 0.6))
keys {
    "L-grave"("Terminal that drops down") { scratchpad("drop") }
}
```

Окна относятся к нему по app id (здесь "drop"). Другие варианты: `Scratchpad.Edge()` выезжает
сверху (`Edge(side = Side.RIGHT)` справа), `Scratchpad.Overlay()` — целый рабочий стол поверх
текущего. Из терминала: `newm cmd scratchpad drop`.

### Широкое окно раздвигает соседей

Если сделать окно шире (Super+Ctrl+L) или выше, соседние окна отодвигаются; при уменьшении
освободившееся место закрывается. Чтобы окна накладывались друг на друга, как было в newm:

```kotlin
view { resizePushes = false }
```

### Проектор или второй монитор: зеркало или расширение

Монитор, подключённый впервые, ставится рядом с экраном ноутбука, и показывается выбор режима;
клавиша экранов ноутбука (на многих F7) показывает его в любой момент. Из терминала:
`newm cmd displays mirror` (одна картинка на обоих), `extend`, `laptop` или `other` (только
внешний). Выбор запоминается для этого монитора.

### Карточки при подключении Wi-Fi, кабеля или Bluetooth

На секунду в середине экрана показывается карточка с большой иконкой (как на Mac):

```kotlin
osd { connections = "cards" }   // по умолчанию; "text" — короткая строка; "off" — ничего
```

В истории буфера обмена можно закреплять записи (Ctrl+P или кнопка с булавкой): они
остаются сверху, их не вытесняет лимит, а закреплённые тексты сохраняются после перезапуска
(~/.local/state/newm/clipboard-pins.json). Tab переключает «Все / Текст / Картинки / Закреплённые».

### Скриншоты подробно

```kotlin
screenshots {
    enabled = true
    folder = "~/Pictures/Screenshots"
    save = true; copy = true        // файлом и в буфер обмена
    pointer = false                 // курсор на снимке
    toast = true                    // «Снимок сохранён» на секунду
    start = "region"                // выбор начинается с "region", "window" или "screen"
    delay = 0                       // секунд до снимка
    sharpWindows = true             // часть обзора собирается из окон — чётко
    sharpBackground = "none"        // фон под ними: "none" (прозрачный), "#RRGGBB", "theme"
    fileName = "Screenshot from {date} {time}"   // {date}, {time}, {kind}
    format = "png"; quality = 92    // или "jpg" (качество 10..100)
    then = "satty --filename {file}"            // команда для каждого файла (редактор)
}
```

В обзоре (одиночное нажатие Super) выделите область поверх окон: снимок собирается из
самих окон в их настоящем размере — каждое чёткое, будто на весь экран, — на тех местах, где
они видны. В меню питания на панели тоже есть «Снимок экрана…».

### Обои: следуют за видом или неподвижны

```kotlin
background { mode = "static" }   // "follow" (по умолчанию): двигаются и масштабируются с видом
```

### История буфера обмена подробно

```kotlin
clipboard {
    enabled = true
    size = 50                       // закреплённые хранятся сверх этого
    pictures = true; files = true   // картинки и скопированные файлы тоже
    keepPins = true                 // закреплённые тексты переживают перезапуск
    ignore = listOf("keepassxc", "bitwarden", "1password")   // от этих не сохраняется
    maxPictureMb = 16; maxText = 200000
}
```

«Очистить» удаляет всё, кроме закреплённого; стрелочка рядом — только текст, картинки или
файлы (серые, если такого нет). Tab переходит между частями окна, стрелки или h j k l двигают
внутри, Enter выполняет.

### Быстрые действия

Кнопка-сетка на панели (перед кнопкой питания) открывает быстрые действия: яркость экрана,
кофеин (стрелка — на сколько), скриншот, историю буфера обмена, светлую или тёмную тему, цвета
и клавиши. Колесо мыши над ней меняет яркость. `bar { quickButton = false }` убирает её;
добавьте "quick" в список, чтобы поставить её в другое место.

### Перемещение окон мышью и обзор

Super + тянуть левой кнопкой — перемещает окно под курсором, Super + тянуть правой — меняет
его размер (как в Hyprland); на тачпаде Super и два пальца тоже меняют размер. Super и простое
движение мыши больше ничего не делают:

```kotlin
mouse { superMove = "button" }   // "motion": Super и движение мыши двигают окно, как было в newm
```

В обзоре (одиночное нажатие Super) окна не принимают нажатия: щелчок выбирает окно, и обзор
закрывается.

```kotlin
overview {
    input = false     // true: окна принимают нажатия, как было в newm
    choose = true     // щелчок выбирает окно
}
```

### Уменьшение окон и чёткое изменение размера

Окно размером в одну клетку (первое окно занимает весь экран одной клеткой) всё равно можно
сделать уже или ниже (Super+Ctrl+H/K, Super+тянуть ПКМ): сначала сетка становится мельче
(каждая клетка 2 × 2, на экране ничего не двигается). Меньше, чем позволяет сама программа,
окно не станет (Spotify: 800 × 600).

Во время изменения размера окно рисуется в своём настоящем размере, без растяжения, поэтому
не мерцает, когда приходит новая картинка. `view { crispResize = false }` — растягивать, как
было в newm.

### Перезапуск с сохранением окон

`newm cmd restart keep` перезапускает newm (новая сборка, изменённая настройка) и потом снова
открывает ваши окна: каждая программа запускается заново (терминал — в папке, где была его
оболочка), а её окно встаёт на прежнее место. Сохраняется командная строка программы; что было
открыто внутри неё (вкладки, файлы), программа восстанавливает сама.
