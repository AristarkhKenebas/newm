# Установка

[English](../en/install.md) · **Русский**

## Что понадобится

- **Java 27** (в Arch: `sudo pacman -S jdk-openjdk`).
- **Терминал.** newm откроет тот, что у вас есть: `$TERMINAL`, а если его нет — первый
  найденный из alacritty, foot, kitty, wezterm, ... Чтобы выбрать свой, укажите его
  в конфигурации (`val terminal = "foot"`).
- Желательно также:
  - `xorg-xwayland` — для программ X11;
  - `xdg-desktop-portal-gtk` (или `-wlr`) — для демонстрации экрана и окон выбора файлов;
  - `grim` (снимки экрана), `brightnessctl`, `wireplumber` или `pulseaudio` (клавиши яркости и громкости).

## Сборка и установка

```sh
git clone https://github.com/AristarkhKenebas/newm
cd newm
./install.sh            # для всех пользователей: /usr/local (спросит ваш пароль)
./install.sh --user     # или только для вас: ~/.local
```

Скрипт делает три вещи:

- собирает newm;
- добавляет команду `newm` в ваш PATH;
- добавляет newm в список сеансов на экране входа, а стартовую конфигурацию кладёт в `/etc/newm`.

Чтобы потом обновиться: `git pull && ./install.sh`.

В NixOS вместо этого используйте модуль (см. [Nix](other-formats.md#nix)).

## Запуск

- **Из текстовой консоли** (Ctrl+Alt+F2, войдите в систему): наберите `newm`.
- **С экрана входа** (ly, SDDM, GDM, greetd): выберите «newm».
- **Внутри вашего текущего рабочего стола, чтобы попробовать**: запустите `newm` в терминале.
  newm откроется как обычное окно, а на вашем рабочем столе ничего не изменится.

## Первый запуск

newm создаёт папку с вашей конфигурацией, `~/.config/newm/`:

- `config.kts`: все настройки, у каждой есть пояснение. Открывайте его в любом редакторе,
  прямо пока newm работает. Каждый раз, когда вы сохраняете файл, newm сразу его применяет.
- `README.md`: какой файл из этой папки читает newm.
- `examples/`: та же конфигурация на Lua и JSON.
- `bars/`: панели на выбор (см. [Панели](bars.md)).

Первые клавиши:

- **Logo+Return**: терминал;
- **Logo+d**: лаунчер;
- **Logo+q**: закрыть окно;
- **Logo+Shift+Escape**: выйти из сеанса.

«Logo» — это клавиша с логотипом Windows или Super (клавиша Super/Windows). Дальше: [Каждый день](using.md).
