# Панели

[English](../en/bars.md) · **Русский**

У newm есть своя панель, и любая другая программа-панель работает так же хорошо. Можно
обойтись и вовсе без панели. Окна всегда освобождают место под ту панель, что есть.

## Своя панель newm

Она включена сразу: три полупрозрачных острова у верхнего края экрана. Пока окно на весь
экран, она уходит, а в обзоре остаётся.

- **Слева: меню и окно.** Кнопка меню (три полоски) открывает лаунчер. Рядом — значок и
  заголовок окна в фокусе: щелчок показывает все окна (обзор), щелчок средней кнопкой
  закрывает окно. Добавьте `"wall"` — получится маленькая карта стены: каждое окно — плитка,
  окно в фокусе — цветом акцента, видимая часть обведена; щелчок показывает все окна (обзор),
  колесо перебирает окна.
- **Посередине: часы.** Щелчок открывает календарь (стрелки меняют месяц, щелчок по названию
  месяца возвращает к сегодняшнему дню).
- **Справа: трей и компьютер.**
  - **Трей**: значки программ, работающих в фоне (Telegram, Discord, Steam, ...). Щелчок
    активирует программу, правый щелчок открывает её меню, средний выполняет её второе
    действие, колесо прокручивает. При наведении видна подсказка программы. nm-applet и
    blueman не показываются, потому что Wi-Fi и Bluetooth панель показывает сама
    (`trayHide`).
  - **Раскладка клавиатуры** (EN, RU), если их несколько: щелчок переключает.
  - **Bluetooth** (если он есть в компьютере): вкл и выкл, ваши устройства (подключить,
    отключить, забыть, их заряд) и устройства рядом для сопряжения — всё в окошке.
  - **Wi-Fi** (или кабель): вкл и выкл, сети поблизости; щелчок подключает (новая сеть
    спрашивает пароль в маленьком окне посреди экрана; если пароль сохранённой сети не подошёл,
    он спрашивается снова и меняется только пароль, а не остальные её настройки), от известной
    можно отключиться или забыть её. Сети ищутся только при открытии окошка
    (`network { scanOnOpen = false }` — только кнопкой обновления).
  - **Звук**: колесо меняет громкость, средний щелчок выключает звук. Щелчок открывает
    громкость, выбор динамиков или наушников и микрофон.
  - **Батарея**: на сколько хватит заряда или сколько до полной зарядки, переключатель
    процентов на панели и режим питания (энергосбережение, баланс, мощность).
  - **Уведомления** (колокольчик; маленькое число на нём — сколько новых): история
    уведомлений, новые сверху, по программам. Щелчок по уведомлению открывает его программу,
    × закрывает его; «Очистить всё» и переключатель «Не беспокоить» (без карточек, только
    история; средняя кнопка на колокольчике тоже переключает). См. [Уведомления](configuration.md#уведомления).
  - **Быстрые настройки** (сетка из четырёх квадратов; чашка, пока включён кофеин): см. ниже.
    Колесо над кнопкой меняет яркость.
  - **Кнопка питания**: заблокировать, сон, гибернация (если компьютер умеет), выйти,
    перезагрузка, выключить. Последние три переспрашивают («Нажмите ещё раз»), чтобы
    случайное движение не завершило сеанс. Какие пункты, какие переспрашивают и что каждый
    запускает — `power { }` ниже.

Щелчок в любом другом месте закрывает окошко. При наведении на остров видно, что это (через
`hintDelayMs`). Что делают щелчок, средняя кнопка и колесо на каждом модуле, можно поменять:
см. [Щелчки и колесо](#щелчки-и-колесо).

### Быстрые настройки

Как на телефоне:

- ползунок **яркости** (если яркость экрана можно менять: brightnessctl);
- **Wi-Fi** и **Bluetooth**: квадрат включает и выключает, надпись открывает их окошко;
- **Кофеин**: экран не гаснет (ни блокировки, ни отключения экрана, ни сна); надпись
  предлагает 30 минут, 1 час, 2 часа или пока не выключите;
- **светлая или тёмная** тема: для newm и ваших программ вместе, запоминается до следующего
  запуска;
- **снимок экрана**: выбор снимка;
- **история буфера обмена**;
- **цвета**: из обоев (со стилем: тональная, яркая, выразительная, нейтральная,
  монохромная) или классические цвета newm;
- **подсказка по клавишам**;
- **не беспокоить** (без карточек уведомлений);
- **энергосбережение** (если работает power-profiles-daemon); при выключении возвращается
  режим, который был до него.

Какие плитки, в каком порядке, и свои плитки:

```kotlin
quickSettings {
    // две широкие плитки — ряд; широкая одна делит ряд с двумя маленькими; остальные маленькие — по пять в ряд
    tiles = listOf("wifi", "bluetooth", "caffeine", "dark", "screenshot", "clipboard", "colors", "keys", "dnd", "power_saver", "vpn")
    tile("vpn", icon = "lock", label = "VPN", wide = false) {
        onClick { launch("vpn-toggle") }
        isOn("vpn-status --quiet")      // команда (включено, если она успешна) или isOn { ... } на Kotlin
    }
}
caffeine { choices = listOf(30, 60, 120, 0) }   // минуты; 0 — пока не выключите
```

Значок — символ Material, который есть в newm (`wifi`, `bluetooth`, `coffee`, `dark_mode`,
`palette`, `keyboard`, ...), один из значков newm (`lock`, `bell`, `power`, `settings`,
`moon`, `sun`, ...), значок вашей темы значков (`firefox`) или файл картинки.

### Что нужно панели

Каждая часть узнаёт о компьютере через обычную службу или программу. Без неё эта часть пуста
или ничего не делает, остальное работает:

| Часть | Нужно |
|---|---|
| Wi-Fi | NetworkManager |
| Bluetooth | BlueZ (bluetoothd) |
| окно громкости | `pactl` (PulseAudio или pulse-часть PipeWire) |
| клавиши громкости | `wpctl` (WirePlumber) |
| яркость | `brightnessctl` |
| режимы питания, энергосбережение | power-profiles-daemon |
| батарея | ничего (`/sys/class/power_supply`) |

Команды можно задать свои (`{percent}` в них — значение):

```kotlin
sound {
    wheelStep = 2                                   // процентов за щелчок колеса над громкостью
    setVolume = "pamixer --set-volume {percent}"    // не задано: wpctl, иначе pactl
    getVolume = "pamixer --get-volume-human"        // "45%" или "Volume: 0.45 [MUTED]" как у wpctl
}
brightness {
    wheelStep = 5                                   // процентов за щелчок колеса над быстрыми настройками
    minimum = 1                                     // ниже панель не ставит
    device = "intel_backlight"                      // не задано: первое в /sys/class/backlight
    set = "light -S {percent}"                      // не задано: brightnessctl (для device)
    get = "light -G"                                // не задано: из /sys/class/backlight
}
network { wifiName = "iwgetid -r" }                 // не задано: nmcli, иначе iwgetid
battery {
    low = 20                                        // ниже — цвет предупреждения
    critical = 10                                   // ниже — цвет опасности
    onCritical { launch("notify-send -u critical 'Батарея садится'") }   // один раз каждый раз, без зарядки
}
power {
    entries = listOf("lock", "suspend", "hibernate", "logout", "reboot", "poweroff")
    confirm = listOf("logout", "reboot", "poweroff")   // переспрашивают
    suspend = "systemctl suspend-then-hibernate"   // команда; не задано: energy { suspendCommand }
    reboot = "systemctl reboot"                    // hibernate, poweroff: systemctl (без него loginctl)
    onLock { ensureLocked() }                      // или действие: onSuspend { }, onLogout { }, ...
}
calendar {
    weekend = listOf("SATURDAY", "SUNDAY")          // бледнее
    firstDay = "MONDAY"                             // не задано: как принято в языке
    weekNumbers = true                              // номера недель слева
}
```

### Настройки

Все необязательны:

```kotlin
panels {
    topBar {
        enabled = true
        height = 32                     // высота острова
        margin = 6                      // отступ от краёв экрана
        cornerRadius = 12
        theme = "auto"                  // "auto", "light", "dark"
        font = "Inter"                  // не задано: системный шрифт без засечек
        fontSize = 13
        left = listOf("window")
        center = listOf("clock")
        right = listOf("tray", "layout", "bluetooth", "network", "volume", "battery", "notifications", "power")
        clock = "HH:mm"                 // шаблоны java.time: "h:mm a", "HH:mm:ss"
        date = "EEE d MMM"              // "" — без даты
        accentColor = "#88C0D0"         // а также islandColor, textColor
        iconSize = 16
        showPercent = true              // проценты громкости и батареи
        showPassive = false             // значки трея, которые говорят, что простаивают
        titleWidth = 360                // наибольшая ширина заголовка окна
        trayHide = listOf("nm-applet", "blueman")
        menuButton = true               // кнопка меню первой слева
        quickButton = true              // быстрые настройки перед кнопкой питания
        notificationsButton = true      // колокольчик перед быстрыми настройками
        layoutNames = mapOf("us" to "EN", "de(neo)" to "NEO")   // подписи раскладок
        outputs = listOf("eDP-1")       // мониторы с панелью; пусто (по умолчанию) — все
        clockHint = "EEEE, d MMMM yyyy" // подсказка часов; "" — без неё
        hintDelayMs = 800               // сколько держать указатель до подсказки
    }
}
```

Каждый остров показывает свои модули по порядку, пустой список убирает остров. Модули:
`menu`, `wall`, `window`, `clock`, `tray`, `layout`, `bluetooth`, `network`, `volume`,
`battery`, `notifications`, `quick`, `power` и `texts`, а также ваши (ниже).
`notifications` и `quick` всегда добавляются перед `power` (и в `right`, написанный вами),
если вы не поставили их сами и не выключили (`quickButton = false`,
`notificationsButton = false`). `menu` добавляется только в `left` newm: `left`, написанный
вами, показывается как написан (или уберите `menuButton = false`). Имя, которое не
является модулем, показывается как есть, текстом.

Часы, дата и календарь следуют `language`. На мониторе не из `outputs` панель не рисуется
(окна всё равно оставляют под неё место).

### Свои модули

```kotlin
panels {
    topBar {
        right = listOf("vpn", "tray", "volume", "battery", "power")
        module("vpn") {
            command("vpn-status")       // первая строка вывода — текст (или text { "..." } на Kotlin)
            everySeconds = 10           // как часто спрашивать (5)
            timeoutSeconds = 5          // команда дольше — останавливается
            icon = "lock"               // необязательно: как у плитки быстрых настроек
            onClick { launch("vpn-toggle") }
            onMiddle { }                // а также onRight { }
            onScroll { dy -> }          // щелчки колеса: вниз больше, вверх меньше
        }
    }
}
```

Команда запускается как в оболочке, вне потока композитора, так что медленная команда не
останавливает экран. Модуль без текста и без значка не показывается.

### Щелчки и колесо

Что делают щелчок, средняя и правая кнопки и колесо на модуле:

```kotlin
panels {
    topBar {
        on("window") { middle(null) }                       // средний щелчок ничего не закрывает
        on("volume") { middle { launch("pavucontrol") } }
        on("clock") { click { launch("gnome-calendar") } }
        on("wall") { scrollUp { move(0, -1) }; scrollDown { move(0, 1) } }
        on("quick") { off() }                               // совсем ничего
        // Колесо над пустым местом панели и часами: фокус идёт в ту сторону (так в newm по умолчанию)
        wheel { up { move(0, -1) }; down { move(0, 1) }; left { move(-1, 0) }; right { move(1, 0) } }
    }
}
```

Слоты: `click`, `middle`, `right`, `scrollUp` и `scrollDown`, каждый — действие или `null`
(ничего); не заданное остаётся как в newm (правая кнопка делает то же, что щелчок). Модули —
перечисленные выше и ваши. У newm: `wall` (щелчок — обзор; колесо — окна), `window` (щелчок —
обзор; средняя — закрыть), `clock` (календарь), `layout` (щелчок и колесо — переключить),
`volume` (окошко; средняя — выключить звук; колесо — громкость), `quick` (окошко; колесо —
яркость), `notifications` (история; средняя — не беспокоить), у остальных щелчок открывает их
окошко. `wheel { off() }` — колесо над пустым местом ничего не делает.

В JSON (и таблицах Lua) так же:

```json
"panels": { "top_bar": {
  "on": { "window": { "middle": null }, "volume": { "middle": "launch pavucontrol" } },
  "wheel": { "up": "move 0 -1", "down": "move 0 1", "left": false, "right": false },
  "modules": { "vpn": { "command": "vpn-status", "every_seconds": 10, "icon": "lock", "on_click": "launch vpn-toggle" } }
} }
```

`texts` показывает тексты из `texts { ... }`, которые запрашиваются каждую секунду:

```kotlin
panels {
    topBar {
        right = listOf("texts", "tray", "battery", "power")
        texts { listOf(cpu(), memory(), temperature()) }
    }
}
```

Готовые тексты: `wifi()`, `cpu()`, `memory()`, `temperature()`, `battery()` и `user()`, а
также `date()` и `time()`, которые принимают шаблон (`time("HH:mm")`). Подойдёт и любой код на
Kotlin, который возвращает текст.

`bottomBar { }` — то же самое у нижнего края экрана.

### Окошки по клавише

`newm cmd bar calendar` (или `volume`, `network`, `bluetooth`, `battery`, `power`, `quick`,
`colors`, `tray 0`, `close`) открывает окошко, так что это может сделать и клавиша:

```kotlin
keys { "L-Escape"("Меню питания") { command("bar", "power") } }
```

### Классическая панель

`style = "classic"` возвращает панель старого newm: полосу текстов вдоль края экрана. В
вашей папке `bars/classic.kts` она готова для вставки, сверху и снизу.

## Без панели

```kotlin
panels {
    topBar { enabled = false }
}
```

## waybar или любая другая панель

Выключите свою панель newm, и пусть newm запускает вашу:

```kotlin
panels {
    topBar { enabled = false }
    bar { cmd = "waybar" }
}
```

- newm запускает панель снова, если она завершилась.
- `visibleFullscreen = true` оставляет её поверх окон на весь экран (по умолчанию она уходит).

Панель можно запускать и в `onStartup { launch("waybar") }` или своими скриптами. Работает
любая панель на протоколе layer-shell: waybar, yambar, eww, ags, sfwbar, ironbar и другие.

**waybar в стиле newm**: он есть в вашей папке, в `bars/waybar/`. Скопируйте его в папку
waybar:

```sh
mkdir -p ~/.config/waybar && cp ~/.config/newm/bars/waybar/* ~/.config/waybar/
```

Панели у левого или правого края тоже работают: окна освобождают место с той стороны.

## Другие панели

Уведомления (mako, dunst, swaync), программы обоев (swaybg, swww), доки и экранные
клавиатуры работают так же: запускайте их в `onStartup { }`. Свои сообщения newm показывает
сам, но для уведомлений программ нужна одна из этих программ. Если вы используете программу
обоев, задайте `background { path = "" }`, чтобы newm не рисовал свои обои.
