# Панели

[English](../en/bars.md) · **Русский**

У newm есть своя панель (бар), но любая другая программа-панель работает так же хорошо.
Можно и вовсе обойтись без панели. Окна всегда освобождают место под панель, какая бы она ни была.

## Собственная панель newm

Она включена с самого начала: три полупрозрачных острова парят у верхнего края экрана.

- **Слева — стена и окно.** Маленькая карта вашей стены: каждое окно — плитка, окно в
  фокусе выделено акцентным цветом, видимая часть обведена. Рядом — значок и заголовок окна
  в фокусе. Клик показывает все окна (обзор), колесо перебирает окна, средний клик по
  заголовку закрывает окно.
- **В центре — часы.** Клик открывает календарь (стрелки листают месяцы, клик по названию
  месяца возвращает к сегодняшнему дню).
- **Справа — трей и состояние компьютера.**
  - Трей: значки программ, работающих в фоне (Telegram, Discord, Steam, nm-applet,
    blueman, ...). Клик активирует программу, правый клик открывает её меню, средний клик
    — её второе действие, колесо прокручивает. При наведении появляется подсказка программы.
  - Bluetooth: включение и выключение, ваши устройства (подключить, отключить, забыть,
    их заряд) и «Find devices» для сопряжения новых — всё прямо во всплывающем окне.
  - Wi-Fi: включение и выключение, сети рядом; клик подключает (новая сеть спрашивает
    пароль прямо там), подключённую можно отключить или забыть.
  - Звук: колесо меняет громкость, средний клик выключает звук. Клик открывает громкость,
    выбор колонок или наушников, микрофон и яркость экрана.
  - Батарея: на сколько хватит заряда или сколько осталось до полной зарядки, и режим
    питания (экономия, баланс, производительность).
  - Кнопка питания: заблокировать, сон, выйти, перезагрузить, выключить. Последние три
    переспрашивают, чтобы случайный клик не закрыл вашу сессию.

Клик в любом другом месте закрывает всплывающее окно. Цвета следуют светлой или тёмной
схеме ваших программ.

Настройки, все необязательные:

```kotlin
panels {
    topBar {
        enabled = true
        height = 32                     // высота острова
        margin = 6                      // отступ от краёв экрана
        cornerRadius = 12
        theme = "auto"                  // "auto", "light", "dark"
        font = "Inter"                  // не задан: системный шрифт без засечек
        fontSize = 13
        left = listOf("wall", "window")
        center = listOf("clock")
        right = listOf("tray", "layout", "bluetooth", "network", "volume", "battery", "power")
        clock = "HH:mm"                 // шаблоны java.time: "h:mm a", "HH:mm:ss"
        date = "EEE d MMM"              // "" — без даты
        accentColor = "#88C0D0"         // а также islandColor, textColor
        iconSize = 16
        showPercent = true              // проценты громкости и батареи
        showPassive = false             // значки трея, которые сообщают, что бездействуют
        titleWidth = 360                // наибольшая ширина заголовка окна
    }
}
```

Каждый остров показывает свои модули по порядку, а пустой список убирает остров. Модули:
`wall`, `window`, `clock`, `tray`, `layout`, `bluetooth` (раскладка клавиатуры, если их несколько),
`network`, `volume`, `battery`, `power` и `texts`.
Последний показывает тексты из `texts { ... }`, которые запрашиваются каждую секунду:

```kotlin
panels {
    topBar {
        right = listOf("texts", "tray", "battery", "power")
        texts { listOf(cpu(), memory(), temperature()) }
    }
}
```

Готовые тексты: `wifi()`, `cpu()`, `memory()`, `temperature()`, `battery()` и `user()`, а
также `date()` и `time()`, которые принимают шаблон (`time("HH:mm")`). Подойдёт и любой код
на Kotlin, который возвращает текст.

`bottomBar { }` — то же самое, только внизу экрана.

### Всплывающие окна с клавиатуры

`newm cmd bar calendar` (или `volume`, `network`, `battery`, `power`, `tray 0`, `close`)
открывает всплывающее окно, так что это может сделать и клавиша:

```kotlin
keys { "L-Escape" { command("bar", "power") } }
```

### Классическая панель

`style = "classic"` возвращает панель оригинального newm: полосу текстов вдоль края экрана.
В вашей папке файл `bars/classic.kts` с ней готов к вставке, сверху и снизу.

## Без панели

```kotlin
panels {
    topBar { enabled = false }
}
```

## waybar или любая другая панель

Выключите собственную панель newm и пусть newm запускает вашу:

```kotlin
panels {
    topBar { enabled = false }
    bar { cmd = "waybar" }
}
```

- newm перезапускает панель, если она упадёт.
- `visibleFullscreen = false` скрывает её, пока какое-то окно открыто во весь экран.

Панель можно запустить и в `onStartup { launch("waybar") }` или из ваших собственных скриптов.
Работает любая панель, которая использует протокол layer-shell: waybar, yambar, eww, ags, sfwbar,
ironbar и другие.

**waybar в стиле newm**: такая есть в вашей папке, в `bars/waybar/`. Скопируйте её в папку waybar:

```sh
mkdir -p ~/.config/waybar && cp ~/.config/newm/bars/waybar/* ~/.config/waybar/
```

Панели у левого или правого края тоже работают: окна освобождают место с этой стороны.

## Другие панели

Уведомления (mako, dunst, swaync), программы для обоев (swaybg, swww), доки и экранные
клавиатуры работают точно так же: запускайте их в `onStartup { }`. Если вы используете
программу для обоев, укажите `background { path = "" }`, чтобы newm не рисовал свои
обои.
