# newm documentation

**English** · [Русский](../ru/README.md)

newm is a Wayland compositor for laptops and touchpads: your windows live on an endless
wall of tiles, and the screen is a window onto that wall. You move over it with three
fingers and zoom with four.

Start here:

1. [Install](install.md): get newm running, from a text console or your login screen.
2. [Everyday use](using.md): the keys and gestures.
3. [Your configuration](configuration.md): change how newm looks and works. Saving the file
   applies it at once.

Then, when you need them:

- [Every setting](settings.md): all sections and settings, everything a key can do, and `newm cmd`.
- [Bars](bars.md): newm's own bar, waybar and other bars, or no bar at all.
- [Lua, JSON, Nix and the old config.py](other-formats.md): the configuration in another language.
- [When something goes wrong](troubleshooting.md).
- [Working on newm](development.md): building it, and working on newm from inside newm.
