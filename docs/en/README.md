# newm documentation

**English** · [Русский](../ru/README.md)

newm is a Wayland compositor for laptops and touchpads: your windows live on an endless
wall of tiles, and the screen is a window onto that wall. You move over it with three
fingers and zoom with four.

Start here:

1. [Install](install.md): what newm needs, a page for each distribution (NixOS, Arch,
   Debian and Ubuntu, Fedora, openSUSE, Void, Gentoo, Alpine, others), and how to start newm
   from a text console or your login screen.
2. [Everyday use](using.md): the keys and gestures, the overview, the bar, screenshots, the
   clipboard's history, the lock screen.
3. [Your configuration](configuration.md): change how newm looks and works. Saving the file
   applies it at once.

Then, when you need them:

- [Every setting](settings.md): all sections and settings with their defaults, everything a
  key can do, and `newm cmd`.
- [The start](startup.md): programs started with the session, the smooth start and its sound.
- [Animations](animations.md): off by default; newm's look with one line, or each one by name as in Hyprland.
- [Bars](bars.md): newm's own bar and its popups, waybar and other bars, or no bar at all.
- [Lua, JSON, Nix and the old config.py](other-formats.md): the configuration in another language.
- [When something goes wrong](troubleshooting.md).
- [Testing newm](testing.md): a checklist for trying newm, and how to report a problem.
- [Working on newm](development.md): building it, and working on newm from inside newm.
